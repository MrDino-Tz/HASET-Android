# HASETApp (MediConnect) - Project Analysis Report

## 🏥 Overview
**HASETApp** (also referred to as **MediConnect**) is a comprehensive Android-based medical service platform built using **Java** and **XML**. It facilitates a complete ecosystem for patients, doctors, and administrators, covering everything from appointment booking and real-time consultations to pharmacy services and health articles.

## 🏗️ Architecture & Stack
The project follows a modern, scalable **MVVM (Model-View-ViewModel)** architecture with a strong emphasis on separation of concerns.

- **Frontend**: Java with XML-based layouts, utilizing **Material Design 3** for a premium UI/UX.
- **Backend**: **Firebase** (Authentication, Realtime Database, Cloud Messaging, Storage).
- **Local Persistence**: **Room Database** for offline caching or local data management.
- **Networking**: **Retrofit** and **OkHttp** for REST API communication.
- **Media Management**: **Cloudinary** for image/video uploads and **Glide** for efficient image loading.
- **Architecture Components**: ViewBinding, Navigation Component, LiveData, and ViewModel.
- **Target SDK**: 36 (Android 15+), ensuring compatibility with the latest Android features.

## 📁 Key Modules
The application is divided into several high-level modules:

### 1. 👥 Role Management & Auth
- **User Roles**: Patient, Doctor, and Admin.
- **Authentication**: Secure login/registration via Firebase Auth with role-based redirection.
- **Onboarding**: Visual walkthrough for new users and role selection.

### 2. 📅 Appointment System
- **Booking**: Interactive calendar and time-slot selection for patients.
- **Management**: Doctors can approve, decline, or complete appointments.
- **Tracking**: Real-time status updates (Pending, Approved, Declined, Completed).

### 3. 💬 Real-Time Communication
- **Chat**: One-on-one messaging between doctors and patients using Firebase Realtime Database.
- **Video Calls**: Initial implementation/placeholder for video consultations.
- **Notifications**: Push notifications via Firebase Cloud Messaging (FCM).

### 4. 🛒 Healthcare Services
- **Pharmacy**: Browse and search for medicines/products.
- **Articles**: A content center for health articles and tips.
- **Prescriptions**: Digital prescription management (upload and view).

### 5. 🛠️ Administrative Tools
- **Admin Dashboard**: Comprehensive management of users, doctors, appointments, and system banners.
- **Audit Logs**: Tracking system activities for security and compliance.
- **Wallet Management**: Managing doctor earnings and system finances.
